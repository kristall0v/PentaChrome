# PentaChrome

Инструмент для работы с цветом: интерактивное колесо цветов и таблица кодировок.

## Возможности

- **Колесо цветов** — собственный рендер на Canvas (HSV-колесо: угол = оттенок, радиус = насыщенность), без стандартных контролов.
- **Слайдер яркости** (значение V).
- **Таблица кодировок**: HEX, RGB, HSL, HSV, CMYK, HWB.
- **Двусторонняя синхронизация**:
  - выбрали цвет на колесе → все коды пересчитываются автоматически;
  - вписали любой код в таблице → цвет отмечается на колесе, остальные коды пересчитываются.
- **Блок вывода цвета** — крупный свотч с текущим HEX.
- Копирование любого кода в один клик, кнопка случайного цвета.

## Использование

Откройте сайт: <https://kristall0v.github.io/PentaChrome/>

Поддерживаемые форматы ввода:

| Кодировка | Пример |
|---|---|
| HEX | `#ff6b35`, `f43` |
| RGB | `rgb(255, 107, 53)` |
| HSL | `hsl(16, 100%, 60%)` |
| HSV | `hsv(16, 100%, 100%)` |
| CMYK | `cmyk(0%, 58%, 79%, 0%)` |
| HWB | `hwb(16, 21%, 0%)` |

## Технологии

Чистые HTML/CSS/JS, без зависимостей. Шрифты — Google Fonts (Space Grotesk, JetBrains Mono).
